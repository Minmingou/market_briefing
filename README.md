# market_briefing

매일 시황을 모으고, 종목을 분석하고, 카드뉴스까지 만드는 3단계 파이프라인입니다.
각 스크립트는 독립적으로 실행할 수 있고, 앞 단계의 결과물이 다음 단계의 입력이 됩니다.

## 1. 시황 수집 (`collect.py`)

코스피/코스닥(한국투자증권 API), 원달러 환율(Frankfurter), 미국 3대 지수(yfinance)를 모아
`data/YYYY-MM-DD.json`으로 저장합니다.

### KIS API 키 연결 (최초 1회)

1. 발급받은 **실전투자용 앱키/앱시크릿**을 준비합니다.
2. `.env.example`을 복사해 `.env`로 저장하고, 아래처럼 채웁니다.

   ```
   KIS_APP_KEY=발급받은_앱키
   KIS_APP_SECRET=발급받은_앱시크릿
   ```

3. `.env`는 `.gitignore`에 이미 등록돼 있지만, 카드뉴스/영상 등을 공개 저장소에 올릴 계획이면
   한 번 더 확인해두는 걸 권합니다.

이 프로젝트는 **시세 조회만** 하며 주문/매매 기능은 전혀 쓰지 않습니다.

### 실행

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python collect.py
```

성공하면 `data/2026-08-31.json` 같은 파일이 생기고 터미널에 코스피/코스닥/환율/미국지수가
출력됩니다. 최초 실행 시 생기는 `token_cache.json`은 한투 접근토큰 캐시라 지우지 않아도 됩니다.

### 잘 안 될 때

- **"KIS_APP_KEY / KIS_APP_SECRET 환경변수가 없습니다"**: `.env.example`을 `.env`로 이름 바꿨는지 확인
- **401 인증 에러**: 앱키/시크릿이 틀렸거나, 모의투자 키인데 실전투자 URL로 호출한 경우. 모의투자
  계좌라면 `KIS_BASE_URL`을 `https://openapivts.koreainvestment.com:29443`으로 변경
- **국내 지수 실패**: 한투 개발자센터에서 `inquire-index-price` 응답 필드가 바뀌었는지 확인 후
  `collect.py`의 `fetch_kis_index` 수정
- **미국 지수 안 나옴**: yfinance가 일시적으로 끊긴 것. 재시도하거나 계속 문제되면 Finnhub로 교체 고려
- **장 마감 전 실행**: 당일 데이터 대신 전일 데이터가 나올 수 있음. 한국장은 15:30, 미국장은 한국시간
  새벽 이후 실행 권장
- **환율 change/change_rate가 null**: Frankfurter API가 전일 대비 변동을 안 줘서 비워둔 것. 필요하면
  어제 날짜로 한 번 더 호출해 직접 계산하도록 개선 가능

## 2. 기업 분석 (`analyze.py`)

기업을 검색하면 DART 최근 N개년 재무제표 + KIS 실시간 시세를 모아 투자 참고용 리포트를 만듭니다.

### DART API 키 연결 (최초 1회)

[opendart.fss.or.kr](https://opendart.fss.or.kr)에서 무료로 발급받은 키를 `.env`에 채웁니다
(`DART_API_KEY=`). KIS 키는 1단계와 동일한 값을 그대로 씁니다.

### 실행

```bash
python analyze.py 삼성전자
python analyze.py 005930 --years 3   # 종목코드도 가능, 조회 연수 조절 가능
```

### 보여주는 내용

- 기업 개요: 업종/사업 개요(KIS/DART), 상장주식수(KIS), 로고(네이버 금융)
- 현재 시세: 현재가/등락률/시가총액/PER/PBR/EPS/BPS(KIS)
- 배당 정보: 주당배당금/배당수익률/배당성향(DART)
- 최대주주·자기주식 현황(DART)
- 외국인 지분율(KIS 현재가 조회에 포함)
- 감사의견 및 감사인(DART)
- 업종 평균 PER 대비 배수 (네이버 금융 페이지 파싱 — 공식 API 아님, 페이지 구조 변경 시 실패 가능)
- 사업보고서 원문에서 추출한 사업 개요 요약(DART)
- 최근 N개년 실적 추이 및 전년대비 성장률
- 최근 정기공시 링크

결과는 `data/analysis/YYYY-MM-DD_회사명_종목코드.json`으로 저장됩니다. 회사명이 여러 후보와
겹치면(예: "삼성") 후보 목록을 보여주니 더 구체적으로 재검색하면 됩니다. 첫 실행 시 DART 전체
상장사 목록을 내려받아 `data/corp_code_cache.json`에 7일간 캐싱합니다.

### 잘 안 될 때

- **"DART_API_KEY 환경변수가 없습니다"**: `.env`에 키를 채워 넣었는지 확인
- **상장사를 찾지 못함**: 이 스크립트는 종목코드가 있는 상장사만 검색합니다. 정확한 회사명/6자리
  종목코드로 재시도
- **재무제표가 비어있음**: 최근 사업보고서 미공시(연초) 또는 DART 표준 12개 계정과 다른 특수
  양식(금융업 등)일 수 있음
- **KIS 시세만 실패**: 나머지 분석은 정상 진행되고 시세만 N/A로 표시됨. 1단계 401 에러 체크리스트 참고
- **사업 개요/업종 평균 PER이 안 나옴**: 정규식 파싱 방식이라 회사마다 서식이 달라 못 찾을 수 있음.
  에러는 아니고 해당 항목만 N/A/"확인하지 못했습니다"로 표시됨

## 3. 카드뉴스 생성 (`cardnews.py`)

`analyze.py`가 만든 리포트 JSON을 읽어 6장짜리 카드뉴스 PNG를 만듭니다. 네트워크 호출 없이
순수 이미지 렌더링만 하므로 분석 단계와 완전히 분리돼 있습니다.

```bash
python analyze.py 삼성전자        # 1) 분석 리포트 생성
python cardnews.py 삼성전자       # 2) 그 리포트로 카드뉴스 생성
```

`data/analysis/`에서 회사명(또는 종목코드)이 포함된 가장 최근 리포트를 자동으로 찾습니다. 특정
리포트를 지정하려면 `python cardnews.py --file data/analysis/2026-09-04_삼성전자_005930.json`.

### 카드 구성 (6장)

1. 표지 — 기업명, 종목코드, 현재가/등락률, 시가총액/PER/PBR
2. 기업 소개 — 로고, 사업 개요, 업종, 상장주식수, 최대주주 지분율, 배당·자기주식 정보
3. 실적 추이 — 매출액·영업이익·당기순이익 최근 N개년 막대그래프 + 전년대비 성장률
4. 수익성 지표 — 영업이익률·순이익률·ROE·ROA 라인 그래프
5. 밸류에이션·재무안정성 — PER/PBR/EPS/BPS, 52주 최고·최저 대비, 부채비율, 외국인 지분율
6. 핵심 요약 — 규칙 기반 3줄 요약, 최근 공시 링크, 감사의견, 투자 유의사항

결과는 `data/cardnews/{날짜}_{회사명}_{종목코드}/card_1.png ~ card_6.png`에 저장됩니다.
macOS 시스템 한글 폰트(AppleSDGothicNeo)를 쓰므로 별도 설치가 필요 없고, 다른 OS는
`cardnews.py`의 `FONT_PATH`를 해당 OS 한글 폰트 경로로 바꿔야 합니다. 로고는 `logo_client.py`가
네이버 금융의 비공식 이미지 URL에서 받아 `data/logos/`에 캐싱하며, 일부 종목은 로고가 없을 수
있는데 그 경우 조용히 로고 없이 카드가 생성됩니다.

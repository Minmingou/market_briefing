# market_briefing — 1단계: 데이터 수집

매일 코스피 / 코스닥(한국투자증권 API) / 원달러 환율(Frankfurter) / 미국 3대 지수(yfinance)를
모아서 `data/YYYY-MM-DD.json`으로 저장하는 스크립트입니다.
이 결과물이 다음 단계(시황 요약 텍스트 생성)의 입력이 됩니다.

## 0. 한투 API 키 연결하기 (최초 1회)

1. 이미 발급받으신 **실전투자용 앱키 / 앱시크릿**을 준비합니다.
2. `.env.example` 파일을 복사해서 `.env` 라는 이름으로 저장합니다.
3. `.env` 파일을 열어서 아래처럼 실제 값을 채웁니다.

   ```
   KIS_APP_KEY=발급받은_앱키
   KIS_APP_SECRET=발급받은_앱시크릿
   ```

4. `.env` 파일은 **절대 외부에 공유하거나 git에 올리지 마세요.**
   `.gitignore`에 이미 등록해뒀지만, 카드뉴스/영상 등을 공개 저장소에 올릴 계획이 있다면
   한 번 더 확인하는 걸 추천드려요.

이 프로젝트는 **시세 조회만** 하고 주문/매매 관련 기능은 전혀 사용하지 않습니다.

## VS Code에서 실행하기

1. 이 `market_briefing` 폴더를 VS Code로 열기
2. 터미널(Ctrl+`)에서 가상환경 만들기

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Mac/Linux
   source venv/bin/activate
   ```

3. 패키지 설치

   ```bash
   pip install -r requirements.txt
   ```

4. 실행

   ```bash
   python collect.py
   ```

5. 성공하면 `data/2026-08-31.json` 같은 파일이 생기고,
   터미널에 코스피/코스닥/환율/미국지수가 JSON으로 출력됩니다.
   최초 실행 시 `token_cache.json`이 생기는데, 이건 한투 접근토큰을 캐싱해서
   불필요하게 자주 재발급받지 않기 위한 용도입니다. 지우지 않아도 됩니다.

## 잘 안 될 때 체크리스트

- **"KIS_APP_KEY / KIS_APP_SECRET 환경변수가 없습니다" 에러**: `.env` 파일을 만들지 않았거나,
  파일명이 `.env.example`인 채로 남아있는 경우입니다. `.env`로 이름을 바꿨는지 확인하세요.
- **401 인증 에러**: 앱키/시크릿이 틀렸거나, 모의투자용 키인데 실전투자 URL로 호출한 경우입니다.
  모의투자 계좌라면 `collect.py`의 `KIS_BASE_URL`을
  `https://openapivts.koreainvestment.com:29443`으로 바꿔야 합니다.
- **국내 지수가 계속 실패할 때**: 한투 API 문서(개발자센터 로그인 후 [API 문서] 메뉴)에서
  `inquire-index-price` 응답 필드가 바뀌었는지 확인하고, `collect.py`의
  `fetch_kis_index` 함수를 그에 맞게 수정하면 됩니다.
- **미국 지수가 안 나올 때**: yfinance는 가끔 일시적으로 끊깁니다. 몇 분 뒤 재시도하거나,
  꾸준히 문제가 되면 Finnhub(무료 API 키 발급)로 교체하는 걸 권장합니다.
- **장 마감 전에 실행하면**: 당일 데이터가 아직 안 나와서 전일 데이터가 나올 수 있습니다.
  한국장은 15:30, 미국장은 한국시간 새벽 이후에 실행하는 걸 권장합니다.
- **환율에 change/change_rate가 null인 이유**: Frankfurter API는 전일 대비 변동을 따로 주지
  않아서 비워뒀습니다. 필요하면 어제 날짜로 한 번 더 호출해서 직접 등락률을 계산하도록
  개선할 수 있어요 — 원하시면 다음 단계에서 추가해드릴게요.

## 다음 단계 (2단계, 아직 미구현)

`generate.py`를 만들어서 이 JSON을 Claude API에 넘기고,
"오늘의 시황 한 줄 요약 + 카드뉴스용 문구"를 자동으로 받아오는 스크립트를 추가할 예정입니다.

# market_briefing — 2단계: 기업 분석 (`analyze.py`)

기업을 검색하면 DART(전자공시시스템) 최근 N개년 재무제표 + KIS 실시간 시세를 모아서
투자 참고용으로 한눈에 보기 쉬운 리포트를 만드는 스크립트입니다.
카드뉴스는 이 리포트(JSON)를 입력으로 다음 단계에서 만들 예정입니다.

## 0. DART API 키 연결하기 (최초 1회)

1. [opendart.fss.or.kr](https://opendart.fss.or.kr) 에서 무료로 발급받은 **오픈API 인증키**를 준비합니다.
2. `.env` 파일을 열어서 아래 줄을 실제 값으로 채웁니다.

   ```
   DART_API_KEY=발급받은_키
   ```

3. KIS 키는 `collect.py`와 동일한 `KIS_APP_KEY` / `KIS_APP_SECRET`을 그대로 사용합니다
   (이미 위 0번에서 설정하셨다면 추가 작업이 필요 없습니다).

## 실행 방법

```bash
source venv/bin/activate
pip install -r requirements.txt   # dart_client.py, kis_client.py는 requests/python-dotenv만 사용
python analyze.py 삼성전자
python analyze.py 005930 --years 3   # 종목코드로도 검색 가능, 조회 연수 조절 가능
```

## 무엇을 보여주나요

- **기업 개요**: 업종 · 사업 개요 요약 (KIS/DART), 상장주식수 (KIS), 로고 (네이버 금융)
- **현재 시세**: 현재가, 등락률, 시가총액, PER/PBR/EPS/BPS (KIS)
- **배당 정보**: 최근 사업연도 기준 주당배당금 / 배당수익률 / 배당성향 (DART 배당에 관한 사항)
- **최대주주 현황**: 최대주주 + 특수관계인 합산 지분율 (DART 최대주주 현황)
- **자기주식 현황**: 발행주식 대비 자사주 보유 비율 (DART 자기주식 취득 및 처분 현황)
- **외국인 지분율**: 외국인이 보유한 주식 비율 (KIS 현재가 조회에 포함된 값, 별도 API 호출 없음)
- **감사의견**: 최근 사업연도 회계감사의견(적정/한정 등)과 감사인 (DART 회계감사인의 명칭 및 감사의견)
- **업종 평균 PER 비교**: 동일업종 평균 PER 대비 현재 PER 배수 (네이버 금융 종목 페이지 기준, 공식 API가 아니라 페이지 구조가 바뀌면 조회에 실패할 수 있음)
- **사업 개요**: 최근 사업보고서 원문에서 추출한 "사업의 개요" 앞부분을, "당사는/당사가" 같은
  공시 특유의 문체 대신 회사명으로 시작하도록 다듬고 1~2문장으로 요약해서 보여줍니다
  (DART 공시서류 원본)
- **최근 N개년 실적 추이**: 매출액 / 영업이익 / 당기순이익 / 영업이익률 / 순이익률 / 부채비율 (DART, 연결재무제표 우선)
- **전년대비 성장률**: 매출 / 영업이익 / 순이익
- **최근 정기공시 링크**: 사업보고서/반기보고서/분기보고서 원문 바로가기

실행할 때마다 `data/analysis/YYYY-MM-DD_회사명_종목코드.json`으로 결과가 저장됩니다.
회사명이 여러 후보와 겹치면(예: "삼성") 후보 목록을 보여주니 더 구체적으로 다시 검색하면 됩니다.

첫 실행 시 DART 전체 상장사 목록을 내려받아 `data/corp_code_cache.json`에 캐싱하고(7일간 재사용),
이후 실행부터는 훨씬 빨라집니다.

## 잘 안 될 때 체크리스트

- **"DART_API_KEY 환경변수가 없습니다" 에러**: `.env`에 `DART_API_KEY`를 채워 넣었는지 확인하세요.
- **"~에 해당하는 상장사를 찾지 못했습니다"**: DART는 비상장사도 포함하지만 이 스크립트는
  종목코드가 있는 **상장사만** 검색합니다. 정확한 회사명이나 6자리 종목코드로 다시 시도해보세요.
- **재무제표가 비어있을 때**: 최근 사업보고서가 아직 공시되지 않았거나(연초), 회사가
  DART 표준 12개 계정과 다른 특수한 재무제표 양식(금융업 등)을 쓰는 경우일 수 있습니다.
- **KIS 시세 조회만 실패할 때**: 나머지 재무제표 분석은 정상 진행되고 시세 부분만 "N/A"로
  표시됩니다. `collect.py`의 401 에러 체크리스트를 참고하세요.
- **사업 개요가 안 나올 때**: 사업보고서 원문(XML)에서 "사업의 개요" 문단을 정규식으로 찾는
  방식이라, 회사마다 서식이 조금씩 달라 못 찾는 경우가 있습니다. 에러는 아니고 카드에
  "사업 개요를 확인하지 못했습니다"로 표시됩니다.
- **업종 평균 PER이 N/A일 때**: 네이버 금융 종목 페이지를 정규식으로 파싱하는 방식이라
  (공식 API 아님), 페이지 구조가 바뀌거나 일시적으로 접속이 안 되면 조회에 실패할 수
  있습니다. 에러는 아니고 카드에서 해당 항목만 N/A로 표시됩니다.

# market_briefing — 3단계: 카드뉴스 생성 (`cardnews.py`)

`analyze.py`가 만든 리포트 JSON을 읽어서 6장짜리 카드뉴스 이미지(PNG)를 만듭니다.
네트워크 호출은 하지 않고 순수하게 이미지만 그리므로, 분석 단계와 완전히 분리되어 있습니다.

## 실행 방법

```bash
python analyze.py 삼성전자        # 1) 먼저 분석 리포트를 만들고
python cardnews.py 삼성전자       # 2) 그 리포트로 카드뉴스를 생성
```

`data/analysis/`에서 회사명(또는 종목코드)이 포함된 가장 최근 리포트를 자동으로 찾습니다.
특정 리포트를 지정하려면 `python cardnews.py --file data/analysis/2026-09-04_삼성전자_005930.json`처럼 실행하세요.

## 카드 구성 (6장)

1. **표지** — 기업명, 종목코드, 현재가/등락률, 시가총액/PER/PBR
2. **기업 소개** — 회사 로고(네이버 금융), 사업 개요 요약, 업종, 상장주식수, 최대주주 지분율,
   배당·자기주식 정보(주당배당금·배당수익률·배당성향·자기주식 비율, DART 공시 기준)
3. **실적 추이** — 매출액·영업이익·당기순이익 최근 N개년 막대그래프(전년대비 성장률 포함)를 한 페이지에 모아서 비교
4. **수익성 지표** — 영업이익률·순이익률 라인 그래프 + ROE(자기자본이익률)·ROA(총자산이익률) 라인 그래프
5. **밸류에이션·재무안정성** — PER/PBR/EPS/BPS, 52주 최고·최저 대비 현재가, 부채비율,
   외국인 지분율, 업종 평균 PER 대비 비교
6. **핵심 요약** — 규칙 기반 3줄 요약, 최근 정기공시 링크, 회계감사의견, 투자 유의사항 안내문

결과는 `data/cardnews/{날짜}_{회사명}_{종목코드}/card_1.png ~ card_6.png`로 저장됩니다.
macOS 시스템 한글 폰트(AppleSDGothicNeo)를 사용하므로 별도 폰트 설치가 필요 없습니다
(다른 OS에서 돌리려면 `cardnews.py`의 `FONT_PATH`를 해당 OS의 한글 폰트 경로로 바꿔야 합니다).

로고는 `logo_client.py`가 네이버 금융의 비공식 이미지 URL(`Stock{종목코드}.png`)에서 받아
`data/logos/`에 캐싱합니다. 공식 문서가 있는 API가 아니라 일부 종목은 로고가 없을 수 있는데,
그 경우 조용히 로고 없이 카드가 생성됩니다(에러 아님).
